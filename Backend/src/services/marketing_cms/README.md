Service de communication, marketing et CMS (Campagne Email/SMS, Articles du site web public, médias)

Fonctionnalités :
- campagnes email/SMS, articles du site web public, médias
- creation du site web du club avec son sous domaine (https://[club_name].gesport.com)
- gestion des médias (images, vidéos, documents)
- creation d'articles de presse pour le club

Technologies : Django + Celery (génération HTML, envoi asynchrone d'emails et webhooks SMS Brevo/Twilio) 

Base de données : PostgreSQL (cms_db)
