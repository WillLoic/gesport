Service de messagerie et de notification 

Fonctionnalités :
- salons de chat internes, notifications push, alertes en direct, la possibilite de creer des groupes, supprimer(par l'administrateur du groupe), quitter ajouter quelqu'un...(toutes la paperasse des applications de messageries) 

Technologies : FastAPI / Python asyncio pour supporter des milliers de WebSockets simultanés 

Base de données : Redis (Pub/Sub) + PostgreSQL
